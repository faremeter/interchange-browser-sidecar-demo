Interchange browser debugger

Attach the Interchange workflow runtime to another browser tab, then let its agent inspect that page's live DOM.

1. Install in the target tab

Open DevTools in a page you want to debug, paste this command into the console, and press Enter.

Creating a short-lived pairing code…

2. Ask the page debugger

Once installation resolves, run this in the target console:

await interchangeDebug.run("What on this page could explain the broken layout?")

Disconnect it with:

await interchangeDebug.disconnect()

The agent can send inspected page content to the configured model. Only attach it to pages whose data you are comfortable sharing. Strict CSP or HTTPS mixed-content rules may block console installation; a browser extension is the intended path for those pages.
